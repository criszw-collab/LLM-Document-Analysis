## SEC sources and limits

The code includes both instructor-specified URLs:

```python
url = 'https://www.sec.gov/files/company_tickers.json'
search_url = f'https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK={cik}&type=8-K&count={count}&output=atom'
```

JSON is decoded as JSON. BeautifulSoup parses Atom XML and filing HTML. SEC submissions JSON adds historical coverage and exact form matching. Requests include an identifying contact header, serial pacing, source caching and bounded transient retries.

The documented scope is primary 8-K plus the first Exhibit 99.1, selected announcement passages and neighboring context, with full-text fallback on keyword misses. Other exhibits are logged as excluded; unreadable or over-budget sources are flagged. Limited coverage and small-model semantic errors can cause misses. An empty extraction is not proof that no product launch occurred. The report describes these limits and cites official documentation.
